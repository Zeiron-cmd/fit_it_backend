models — таблицы базы данных
schemas — какие данные приходят/уходят через API
routers — сами endpoints
services — логика, например авторизация или работа с нейронкой
database.py — подключение к базе


POST /auth/register — регистрация
POST /auth/login — вход
GET /auth/me — получить текущего пользователя


1. Пользователь отправляет email и пароль.
2. Backend проверяет, нет ли такого пользователя.
3. Пароль хешируется.
4. Пользователь сохраняется в базу.
5. При входе backend проверяет пароль.
6. Backend выдаёт JWT-токен.
7. По токену можно получить данные пользователя.
